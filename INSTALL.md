# Запуск

Каталог книг на Yii2 + MySQL. Всё выполняется в контейнерах, PHP и Composer на хосте не нужны.

## Требования

Docker (с плагином `compose`) и `make`. Приложение занимает порт **8082**, MySQL — **33061**;
оба меняются в `.env` (`HTTP_PORT`, `DB_PORT`).

## Первый запуск

```bash
cd src
make init
```

`make init` создаёт `.env` из `.env.example`, собирает образы, поднимает контейнеры,
применяет миграции к рабочей и тестовой базам и наполняет каталог демо-данными.

Приложение — <http://localhost:8082>.

**Вход:** логин `admin`, пароль из `ADMIN_PASSWORD` в `.env` (по умолчанию `admin`).
Учётная запись заводится миграцией-сидером, формы регистрации в приложении нет —
по ТЗ пользователь один, а гость не аутентифицируется.

Перед любым не-локальным запуском обязательно задать в `.env`:

```bash
COOKIE_VALIDATION_KEY=$(docker compose exec -T php php -r 'echo bin2hex(random_bytes(16));')
YII_ENV=prod
YII_DEBUG=0
```

`YII_ENV=prod` закрывает Gii и панель отладки и убирает трассировки из ответов.

## Что смотреть

| Адрес | Что это |
|---|---|
| `/book/index` | каталог книг с поиском по названию, году и автору |
| `/author/index` | авторы; в списке видно число книг |
| `/report/top-authors` | отчёт ТОП-10 авторов за год — открыт всем, включая гостя |

Гость видит только просмотр и кнопку «Подписаться» у автора; добавление, редактирование
и удаление доступны после входа.

## Команды

| Команда | Что делает |
|---|---|
| `make up` / `make down` | поднять / остановить окружение |
| `make migrate` | применить миграции |
| `make demo` | наполнить каталог демо-данными (`make demo args=--fresh` — пересоздать) |
| `make queue` | разобрать очередь SMS-уведомлений одним прогоном |
| `make test` | тесты Codeception (`make test args="Unit"` — только модульные) |
| `make lint` / `make stan` / `make check` | PHP_CodeSniffer, PHPStan level 5, всё вместе |
| `make db` | консоль MySQL |
| `make destroy` | остановить и удалить том с данными |

## SMS-уведомления

При добавлении книги подписчикам её авторов ставится задание в очередь. Постоянного воркера
нет: очередь разбирается разовым прогоном, который подразумевается запускаемым по крону.

```cron
* * * * * cd /path/to/src && docker compose exec -T php php yii sms-queue/run --isolate=0
```

Ключ API берётся из `SMSPILOT_API_KEY`. По умолчанию стоит ключ-эмулятор smspilot.ru:
запросы принимаются, реальные SMS не отправляются.

## Структура

```
config/       конфигурация web-, консольного и тестового приложений
controllers/  диспетчеры: связывают запрос с моделью и выбирают, что вернуть
services/     сценарии приложения: порядок операций и побочные эффекты
models/       данные, правила валидации и выборки
components/   инфраструктура: хранилище обложек, очередь, SMS, спецификации, валидаторы
migrations/   схема БД — единственный её источник, дампа нет
views/        представления
tests/        Codeception: наборы Unit и Functional
docker/       образы и конфигурация nginx, php, mysql
```

Почему разложено именно так и какие решения за этим стоят — в комментариях к классам:
`services/BookService.php`, `components/controllers/CatalogueController.php`,
`components/CoverStorage.php`, `components/validators/IsbnValidator.php`.
